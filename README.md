#  Destinos React

## Descripción

**Destinos React** es una aplicación web que permite explorar países del mundo y armar tu propia lista personal de destinos por visitar. Combina información en tiempo real de la API de países ([REST Countries](https://restcountries.com/)) con una lista de viajes que el usuario puede agregar destinos, marcarlos como visitados o pendientes, asignarles una prioridad y eliminarlos cuando ya no le interesen.

---------------------------------------------------------------------------------------------------------------------------------------------


## Objetivo

El propósito del proyecto es practicar el desarrollo de una aplicación React completa que:

- Consume una **API externa** (REST Countries) para buscar información de países.
- Persiste datos propios del usuario en un **backend simulado** (json-server), permitiendo operaciones **CRUD** completas (crear, leer, actualizar y eliminar).
- Mantiene el estado sincronizado entre distintos componentes (buscador y lista de viajes) sin necesidad de recargar la página.
- Ofrece una interfaz simple e intuitiva para organizar futuros viajes.


-----------------------------------------------------------------------------------------------------------------------------------------------
## Funcionalidades principales

- Buscar cualquier país por nombre y ver su bandera, capital, región y población.
- Agregar el país encontrado a una lista personal de "viajes pendientes".
- Marcar destinos como visitados o pendientes.
- Asignar una prioridad (baja, media, alta) a cada destino.
- Eliminar destinos de la lista.


-----------------------------------------------------------------------------------------------------------------------------------------------
## Tecnologías usadas

- React + Vite
- json-server (API simulada)
- CSS personalizado
